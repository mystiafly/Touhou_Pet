运行模式与生命周期

默认采用「标准模式」，具备全功能文件改写、命令行执行与子 Agent 协同派生能力。

在日常与桌宠聊天时，直接输入 启动agent <具体任务> 即可唤醒智能体执行！例如：
• 启动agent 分析当前项目代码结构并找出潜在性能问题
• 启动agent 帮我写一个一键压缩立绘图片的 Python 脚本

API 引擎绑定与环境

系统会自动将选定引擎的 API Key、Base URL 与 Model 同步注入给 DSH 执行器。

建议 60 ~ 180 秒，防止复杂多步任务无限期卡住对话。
